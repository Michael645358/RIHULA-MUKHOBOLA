# RIHULA Group Goal Calculation Update

The Member Dashboard Group Goal is now calculated dynamically from member goals.

## Formula
Group Goal = sum of every member's individual goal.

If a member has no saved positive goal, the standard individual goal of KSh 5,000 is used because the Member Dashboard already treats KSh 5,000 as the default personal goal.

## Example
- Member A: KSh 5,000
- Member B: KSh 2,000
- Member C: KSh 10,000

Calculated Group Goal = KSh 17,000.

The Group Goal screen also shows:
- Total members counted
- Average individual goal
- Number of members with an explicitly saved goal
- Individual goal breakdown for every member
- Each member's collected amount and percentage toward their own goal

The existing contribution total is used as the amount collected toward the calculated group goal.
