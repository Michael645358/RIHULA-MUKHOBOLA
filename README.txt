RIHULA ADMIN DASHBOARD - COMPLETE FRONTEND

Open admin-dashboard.html in a browser.

Included:
- Dashboard overview
- Members: add, edit, delete, search/filter
- Savings: record, search, delete
- Loans: create, approve, reject, repayment, delete
- Announcements: publish/delete
- Reports: member, savings, loan and financial summary + print
- Statistics and savings target progress
- Association settings
- Admin account and password change
- Local browser storage

IMPORTANT: this is a frontend/localStorage version. It is not a secure multi-user backend. Connect these actions to your existing database/authentication before production deployment.
